# Assets Directory

This directory contains images and media files used in annual report generation.

## Required Files

For the report templates to work, you'll need:

### Logos
- `picc-logo-turtle.png` - PICC turtle logo (PNG with transparency)

### Photos
Place photos in the `photos/` subdirectory:

- `palm-island-beach.jpg` - Cover photo (landscape, min 2000px wide)
- `rachel-atkinson.jpg` - CEO portrait (square, min 400px)
- `luella-bligh.jpg` - Chair portrait (square, min 400px)
- `team.jpg` - Partners/team group photo (landscape)

### Story Images
As you add stories, include their featured images here with descriptive names:
- `photos/digital-service-centre-team.jpg`
- `photos/youth-program-2025.jpg`
- etc.

## Image Requirements

| Type | Format | Min Size | Aspect Ratio |
|------|--------|----------|--------------|
| Cover | JPG | 2000px wide | 3:4 (portrait) |
| Portrait | JPG/PNG | 400px | 1:1 (square) |
| Story Feature | JPG | 1200px wide | 4:3 or 16:9 |
| Gallery | JPG | 600px | Any |

## Notes

- Use high-quality originals for print output
- Ensure you have appropriate consent for all photos
- File names should be lowercase with hyphens (not spaces)
