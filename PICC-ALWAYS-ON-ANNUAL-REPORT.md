# PICC "Always-On" Annual Report System

## Overview for Leadership & Stakeholders

---

## What is the "Always-On" Annual Report?

The traditional annual report is a single document published once per year, often months after the reporting period ends. PICC's **Always-On Annual Report** is a living, digital platform that:

| Traditional Report | Always-On Report |
|-------------------|------------------|
| Published once per year | Updates in real-time |
| Static PDF document | Interactive website |
| Takes months to produce | Auto-populates from data |
| Fixed statistics | Live, current numbers |
| Limited distribution | Accessible to all online |
| Expensive to print/design | Generates PDF on-demand |

**Simple Explanation:** Think of it as a dashboard that's always showing PICC's impact, stories, and achievements - updated as things happen, not just once a year.

---

## How It Works (The Simple Version)

```
                 DATA SOURCES                        THE PLATFORM                    OUTPUTS
           ┌─────────────────────┐              ┌──────────────────┐          ┌─────────────────┐
           │                     │              │                  │          │                 │
           │  Staff Numbers      │──────────────│                  │──────────│  Live Website   │
           │  Service Stats      │              │                  │          │  (Public)       │
           │  Financial Data     │              │   PICC Website   │          │                 │
           │  Community Stories  │──────────────│   Database       │──────────│  PDF Download   │
           │  Photos & Videos    │              │                  │          │  (On-Demand)    │
           │  Leadership Info    │              │                  │          │                 │
           │                     │──────────────│                  │──────────│  Archive        │
           └─────────────────────┘              └──────────────────┘          │  (Historical)   │
                                                                              └─────────────────┘
```

1. **Data goes in** → Staff enter information throughout the year (stories, stats, photos)
2. **Platform organizes it** → The system automatically builds the report
3. **People access it** → Anyone can view the live report or download a PDF

## The Three Annual Report Views

### 1. Live Report (`/annual-report/live`)
**For the CURRENT fiscal year (2024-25)**

- Shows real-time data as it updates
- Red "LIVE" badge indicates current reporting period
- Stats update automatically as data is entered
- Community stories appear as they're published
- Perfect for board meetings, grant applications, stakeholder updates

**Currently Shows:**
- Staff count (currently 197, updating as hires happen)
- 16+ integrated services
- Featured community stories
- Innovation projects
- Leadership & board information
- Financial documents (when uploaded)

### 2. Annual Report by Year (`/annual-report/2024`)
**For COMPLETED fiscal years**

- Full, formatted annual report
- All sections populated with that year's data
- Beautiful design with photos, charts, stories
- Download as PDF
- Share on social media

**Sections include:**
- Executive Summary
- CEO & Chair Messages
- Year Highlights
- Impact Statistics
- Community Voices & Stories
- Service Showcase
- Financial Breakdown (donut chart, dollar breakdown)
- Photo Gallery
- Timeline of Milestones
- Acknowledgments

### 3. Historical Timeline (`/annual-reports`)
**Browse 15+ years of PICC history**

- Horizontal scrollable timeline from 2009 to present
- Filter by era (Foundation, Growth, Transition, Community-Controlled)
- Images extracted from historical PDF reports
- Searchable knowledge base

## Efficient Data Collection Process

### Monthly (5 minutes per service)
Each service manager logs in and updates:
1. Clients served this month
2. Key achievements/milestones
3. Any noteworthy stories
4. Staff changes

### Quarterly (30 minutes total)
Leadership review:
1. Verify all service stats are current
2. Select featured stories for the quarter
3. Update innovation project progress
4. Review and approve new content

### Annually (2-3 hours in May/June)
Report finalization:
1. CEO drafts annual message
2. Chair drafts annual message
3. Finance provides final numbers
4. Communications selects hero images
5. Leadership approves year highlights
