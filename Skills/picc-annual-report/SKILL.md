# PICC Annual Report Design Skill

## Overview

This skill provides design specifications and templates for creating Palm Island Community Company (PICC) annual reports, based on the established 2023-24 visual identity.

---

## Brand Identity

### Organisation
- **Name**: Palm Island Community Company (PICC)
- **Logo**: Stylised turtle with Indigenous dot painting motifs (red, yellow, orange with black outline)
- **Tagline**: "Many Tribes, One People" (Bwgcolman meaning)
- **Values**: Community control, self-determination, empowering Palm Islanders

### Visual Character
The PICC brand reflects:
- Connection to land and sea (Palm Island coastal imagery)
- Indigenous cultural elements (dot patterns, traditional motifs)
- Warmth and optimism (vibrant colours)
- Professionalism with cultural authenticity

- **Headers/Titles**: Ocean Blue or Deep Teal

- **Data tables**: Ocean Blue headers, alternating light blue/white rows
- **Charts**: Use primary palette, avoid red for negative (use muted tones)
- **Backgrounds**: Gradient blues, lavender wave overlays

## Typography

### Headings (Display)
- **Font Family**: Hand-drawn/brush stroke style (similar to "Amatic SC Bold" or custom)
- **Character**: Informal, friendly, slightly imperfect
- **Usage**: Section titles, feature headlines
- **Styling**: Bold weight, generous letter-spacing

### Subheadings
- **Font Family**: Clean sans-serif (Open Sans Bold, Source Sans Pro Bold)
- **Weight**: 600-700
- **Size**: 14-18pt

### Body Text
- **Font Family**: Sans-serif (Open Sans, Source Sans Pro)
- **Weight**: 400 (regular)
- **Size**: 10-11pt
- **Line height**: 1.4-1.5
- **Colour**: #333333 (dark grey) or white on colour backgrounds

### Data/Tables
- **Font Family**: Sans-serif, slightly condensed
- **Size**: 9-10pt
- **Alignment**: Left for text, right for numbers

## Page Layout

### Document Specifications
```
Page Size:      A4 (210mm × 297mm)
Orientation:    Portrait
Margins:        Top: 15mm, Bottom: 20mm, Left: 15mm, Right: 15mm
Bleed:          3mm (for print)
```

### Grid System
- 2-column layout for content pages
- Full-width for feature stories and imagery
- Asymmetric layouts encouraged (60/40 splits)

### Page Numbering
- Centred at bottom
- Small circular background (matches brand colours)
- Sans-serif font, 9pt

---

## Design Elements

### Wave Pattern
Layered organic wave shapes at page bottoms:
```
Layer 1 (back):   Soft Lilac with dot pattern overlay
Layer 2 (front):  Deep Teal/Ocean Blue with dot pattern
Dots:             Small circles (2-3mm), semi-transparent white, scattered
```

### Dot Patterns
- Small circles in organic, non-grid arrangements
- Used within wave shapes and as borders
- Opacity: 30-50%
- Colour: White or slightly lighter than background

### Circular Photo Frames
- Perfect circles for portrait photos
- Dotted border: White dots arranged in arc around top edge
- Shadow: Subtle drop shadow (2px, 10% opacity)

### Section Dividers
- Full-width photography with colour overlay
- Gradient fade at edges
- Title overlaid in brush-stroke font

## Data Visualisation

### Tables
```css
Header row:     Background: #4A7C9B (Ocean Blue), Text: White
Subheader:      Background: #6B9BB8 (Lighter blue), Text: White
Data rows:      Alternating white/#F0F7FA
Border:         None (use colour blocks)
Padding:        8px vertical, 12px horizontal
```

### Bar Charts
- Colours: Use brand palette (Ocean Blue, Lavender, Deep Teal)
- Year comparison: Different shades of same colour family
- Axis labels: Dark grey, 9pt
- Grid lines: Light grey, 0.5pt
- Bar spacing: 60% of bar width

### Pie Charts
- Maximum 6 segments
- Brand colours only
- Legend: Right side, aligned
- Labels: Percentage + category name
- No 3D effects

## Photography Guidelines

### Subject Matter
- Palm Island landscapes (beaches, bush, water)
- Community members in action
- Cultural activities and events
- Service delivery in practice
- Staff portraits (professional but warm)

### Treatment
- High saturation for landscapes
- Warm colour grading
- May use colour overlays (Ocean Blue at 20-30%)
- Circular crop for portraits with dotted border

### Placement
- Full-bleed for section openers
- Contained within columns for in-content images
- Always high resolution (300 DPI minimum)

### Basic Structure
```python
from reportlab.lib.pagesizes import A4
from reportlab.lib.colors import HexColor
from reportlab.pdfgen import canvas
from reportlab.lib.units import mm
from reportlab.pdfbase import pdfmetrics
from reportlab.pdfbase.ttfonts import TTFont

# PICC Brand Colours
PICC_COLOURS = {
    'ocean_blue': HexColor('#4A7C9B'),
    'deep_teal': HexColor('#2D5A6B'),
    'lavender': HexColor('#9B7BB8'),
    'soft_lilac': HexColor('#C4A8D4'),
    'sky_blue': HexColor('#87CEEB'),
    'white': HexColor('#FFFFFF'),
    'dark_text': HexColor('#333333'),
}

def create_picc_report(filename):
    c = canvas.Canvas(filename, pagesize=A4)
    width, height = A4

    # Cover page
    create_cover_page(c, width, height)
    c.showPage()

    # Leadership pages
    create_ceo_message(c, width, height)
    c.showPage()

    # Continue with other sections...

    c.save()

def draw_wave_footer(c, width, height, y_start=60*mm):
    """Draw the layered wave pattern at page bottom"""
    import math

    # Back wave (lilac)
    c.setFillColor(PICC_COLOURS['soft_lilac'])
    p = c.beginPath()
    p.moveTo(0, 0)
    for x in range(0, int(width) + 10, 10):
        y = y_start + 10 * math.sin(x / 50) + 5
        p.lineTo(x, y)
    p.lineTo(width, 0)
    p.close()
    c.drawPath(p, fill=True, stroke=False)

    # Front wave (deep teal)
    c.setFillColor(PICC_COLOURS['deep_teal'])
    p = c.beginPath()
    p.moveTo(0, 0)
    for x in range(0, int(width) + 10, 10):
        y = y_start - 15 + 8 * math.sin(x / 40 + 1) + 3
        p.lineTo(x, y)
    p.lineTo(width, 0)
    p.close()
    c.drawPath(p, fill=True, stroke=False)

    # Add dots
    draw_dots_pattern(c, width, y_start)

def draw_dots_pattern(c, width, y_max):
    """Draw scattered dot pattern"""
    import random
    c.setFillColor(HexColor('#FFFFFF'))
    c.setFillAlpha(0.3)

    for _ in range(80):
        x = random.uniform(0, width)
        y = random.uniform(5*mm, y_max - 10*mm)
        r = random.uniform(1, 2.5)
        c.circle(x, y, r*mm, fill=True, stroke=False)

    c.setFillAlpha(1)

def draw_circular_portrait(c, image_path, x, y, diameter):
    """Draw portrait photo in circle with dotted border"""
    from reportlab.lib.utils import ImageReader

    # Create circular clip
    c.saveState()
    p = c.beginPath()
    p.circle(x, y, diameter/2)
    c.clipPath(p, stroke=False)

    # Draw image
    c.drawImage(image_path, x - diameter/2, y - diameter/2,
                width=diameter, height=diameter, preserveAspectRatio=True)
    c.restoreState()

    # Dotted border arc
    c.setStrokeColor(PICC_COLOURS['white'])
    # Draw dots around top arc
    import math
    for angle in range(-60, 240, 15):
        rad = math.radians(angle)
        dot_x = x + (diameter/2 + 3*mm) * math.cos(rad)
        dot_y = y + (diameter/2 + 3*mm) * math.sin(rad)
        c.circle(dot_x, dot_y, 1.5*mm, fill=True, stroke=False)
```

### Table Generation
```python
from reportlab.platypus import Table, TableStyle
from reportlab.lib import colors

def create_picc_table(data, col_widths=None):
    """Create a PICC-styled data table"""
    table = Table(data, colWidths=col_widths)

    style = TableStyle([
        # Header row
        ('BACKGROUND', (0, 0), (-1, 0), PICC_COLOURS['ocean_blue']),
        ('TEXTCOLOR', (0, 0), (-1, 0), colors.white),
        ('FONTNAME', (0, 0), (-1, 0), 'Helvetica-Bold'),
        ('FONTSIZE', (0, 0), (-1, 0), 10),
        ('BOTTOMPADDING', (0, 0), (-1, 0), 8),
        ('TOPPADDING', (0, 0), (-1, 0), 8),

        # Data rows
        ('FONTNAME', (0, 1), (-1, -1), 'Helvetica'),
        ('FONTSIZE', (0, 1), (-1, -1), 9),
        ('BOTTOMPADDING', (0, 1), (-1, -1), 6),
        ('TOPPADDING', (0, 1), (-1, -1), 6),

        # Alternating row colours
        ('ROWBACKGROUNDS', (0, 1), (-1, -1), [colors.white, HexColor('#F0F7FA')]),

        # Alignment
        ('ALIGN', (0, 0), (-1, -1), 'LEFT'),
        ('ALIGN', (-1, 0), (-1, -1), 'RIGHT'),  # Numbers right-aligned
        ('VALIGN', (0, 0), (-1, -1), 'MIDDLE'),
    ])

    table.setStyle(style)
    return table
```

### Chart Generation
```python
from reportlab.graphics.shapes import Drawing
from reportlab.graphics.charts.barcharts import VerticalBarChart

def create_picc_bar_chart(data, categories, series_names, width=400, height=200):
    """Create a PICC-styled bar chart"""
    drawing = Drawing(width, height)

    chart = VerticalBarChart()
    chart.x = 50
    chart.y = 30
    chart.width = width - 100
    chart.height = height - 60

    chart.data = data
    chart.categoryAxis.categoryNames = categories

    # PICC colours for bars
    colours = [
        PICC_COLOURS['ocean_blue'],
        PICC_COLOURS['lavender'],
        PICC_COLOURS['deep_teal'],
    ]

    for i, colour in enumerate(colours[:len(data)]):
        chart.bars[i].fillColor = colour

    chart.valueAxis.valueMin = 0
    chart.categoryAxis.labels.fontName = 'Helvetica'
    chart.categoryAxis.labels.fontSize = 8
    chart.valueAxis.labels.fontName = 'Helvetica'
    chart.valueAxis.labels.fontSize = 8

    drawing.add(chart)
    return drawing
```

## File Checklist

Before finalising the annual report:

### Content
- [ ] CEO message reviewed and signed off
- [ ] Chair message reviewed and signed off
- [ ] All statistics verified with source data
- [ ] Service descriptions current
- [ ] Staff numbers and percentages accurate
- [ ] Financial summary matches audited accounts
- [ ] Partner list complete and current
- [ ] All dates correct (financial year, reporting period)

### Design
- [ ] PICC logo placed correctly (cover, headers)
- [ ] Colour palette consistent throughout
- [ ] Photography high resolution (300 DPI)
- [ ] Wave patterns applied to all page footers
- [ ] Page numbers sequential
- [ ] Headers consistent across pages

### Accessibility
- [ ] Document tagged for screen readers
- [ ] Alt text for all images
- [ ] Tables have header rows marked
- [ ] Colour contrast meets WCAG AA
- [ ] Font sizes readable (minimum 10pt body)

### Final
- [ ] Proofread by independent reviewer
- [ ] Aboriginal and Torres Strait Islander content reviewed by community
- [ ] Board approval obtained
- [ ] Print-ready PDF (CMYK, bleeds)
- [ ] Web-optimised PDF (compressed, RGB)
