# Annual Report PDF — Page Design Briefs

Reference document for the "Saltwater & Earth" visual refresh.
Each page brief defines the hero element, content blocks, mood, and layout archetype.

---

## Layout Archetypes

1. **Full-Bleed Photo** — Cover, Photo Spread, Back Cover
2. **Portrait + Long Text** — CEO/Chair Messages, Directors Report
3. **Data Dashboard** — Year in Numbers, Financials, Financial Detail
4. **Card Grid** — Services, Highlights, Innovation
5. **Quote Spotlight** — Community Voices, Youth Voices

## Design Principles

1. **Break the grid** — Not every page needs symmetric 2-column. Use 40/60 splits, full-width heroes, single-column quotes.
2. **Photos as heroes** — Cover and Photo Spread should be full-bleed. Community Voices should pair large portraits with quotes.
3. **Decorative elements** — ConstellationPattern, WaveLine, ArcDots, SectionDivider exist and should be used generously as section dividers and page backgrounds.
4. **Typography hierarchy** — Caveat (display) for section titles and pull quotes. PlayfairDisplay for stat numbers. Inter for body.
5. **Color variety** — Each section should have its own personality within the Saltwater & Earth palette. Not everything needs to be white + ocean blue.
6. **Breathing space** — Generous margins, fewer items per page when possible, let content breathe.
7. **Data as storytelling** — Numbers should feel like impact, not a spreadsheet.
