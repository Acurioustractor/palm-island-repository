## The thesis

The annual report doesn't get written. It gets **captured**. Every spread
must trace back to:
- A named person (storyteller_id from EL)
- A named service or project (slug from EL)
- A verified number (sourced + dated)
- A consent-cleared photograph

If any link breaks, the spread shows a clear "needs data" tile — not a
generic placeholder.

## Decision lock — what's IN, what's OUT

**IN for v3 print:**
- All 22 spreads above
- Real storyteller portraits where EL has them
- Service hero photos where EL has them
- All other spreads use entity-tagged photos via slot fallback

**OUT for v3 print:**
- Generic stock photography (anti-pattern: every photo must trace to EL)
- Caveat font for display titles (BRAND.md: reserved for margin notes only)
- Cool blue-grey neutrals (BRAND.md: warm-toned only)
- Purple gradients (BRAND.md: banned)
- Generic Lucide icons for service identity (use bespoke PICC icons)
