# PICC Annual Report — Editorial System

**Version 1.0** | April 2026
**Sibling to:** `PICC-BRAND-STYLE-GUIDE.md` v2.0 (the brand is the foundation; this document is the editorial application of it for the annual report only)

---

## Editorial thesis

**Voice carries equal weight to data, and visual restraint signals confidence.**

Six rules. Three are table stakes. Three are deliberate departures from how every other ACCO annual report looks.

---

## Rule 1 — Photo treatment language (three modes, used consistently)

Every photo in the report is one of three modes. The mode is chosen by what the moment is, not what is convenient.

| Mode | Use | Treatment |
|------|-----|-----------|
| **Cultural opener** | Country, ceremony, Elder portraits, Hull River, on-Country trips | Full-bleed. No caption. No text overlay. The photo speaks. |
| **Editorial spread** | Programs, events, milestones | 3:2 with white-space halo. Italic Inter caption in Driftwood `#6B6560` underneath. |
| **Operational** | Service delivery, staff at work, day-to-day | Card-contained, 8pt corner radius, clipped. Caption optional. |

**Never:** mix modes on a single spread. Never use stock photography. See brand guide §6 for cultural protocols.

---

## Rule 2 — Quote attribution standard

Every attributed quote in the report carries: **name · role/relationship to PICC · year captured.**

> *"We had to make our own way back."*
> — Aunty Ethel · Elder, Stolen Generations survivor · 2024

**Never** "a community member." **Never** "one staff member said." Where consent prevents naming, the quote does not run. Anonymous quotes belong in research papers, not in our annual report.

This is dignity, and it is the editorial backbone of CLAUDE.md's "Real Data Only" rule. Pull from `elder_quotes` (validated, public), `extracted_quotes`, and `interviews.themes`. If the row does not have a name and a year, the row does not get used.

---

## Rule 3 — Decoration cadence (one motif per spread, max)

The brand offers seven decorative motifs (concentric dots, arc dots, star marker, section divider, corner brackets, constellation, wave, gradient bar). Spend them like currency.

**Allowed to layer motifs:** Cover · Back Cover · Bwgcolman Way anchor spread. Three pages, total.

**Everywhere else:** pick one motif. If a page already has a strong photo, no motif at all.

If you find yourself reaching for a second motif "to fill space," the page has the wrong content, not too little decoration.

---

## Rule 4 — Caveat earns ONE additional context: Elder pull-quotes only

The brand reserves Caveat for display use. **This document grants one documented exception.**

| Voice type | Quote treatment |
|------------|-----------------|
| **Elder** | Caveat 22pt italic, ≤25 words, attributed, Turtle Red `#8B1A1A` left border, optional Corner Brackets motif |
| **Staff** | Inter 11pt italic, Ocean `#0B4F6C` left border |
| **Community member** | Inter 11pt italic, Ocean left border |
| **Funder / partner** | Inter 11pt italic, Driftwood left border |
| **Vision / aspiration quote** | Inter 11pt italic, Mangrove left border |

The Caveat exception applies only to Elder pull-quotes ≤25 words. Longer Elder passages run as Inter italic body. This is not a license to scatter Caveat across the document; it is a single, structural decision that makes Elder voice typographically sovereign in a way that reflects how Bwgcolman culture treats Elder knowledge.

**Cost:** one documented brand exception.
**Gain:** Elder voice is visually distinct from staff, community, and funder voices in a way no other ACCO annual report achieves.

---

## Rule 5 — Voice-first column grammar (every data page)

Every page that contains data — stats, charts, finances, KPIs, services directory rows — uses a fixed two-column rhythm:

```
┌───────────────────────────────┬─────────────┐
│                               │             │
│  Numbers / chart / cards      │  One voice  │
│  (66% / 327pt content width)  │  (33%)      │
│                               │             │
│                               │  attributed │
│                               │  quote      │
│                               │             │
└───────────────────────────────┴─────────────┘
```

The right column is always the same x-coordinate across every data page in the report. Within three pages, the reader trains: *"the number, and the human it is about, side by side."*

**Cost:** ~33% less room for stat cards on the left. Forces editorial discipline.
**Gain:** the report can never accidentally become a spreadsheet. Most annual reports silo voices into a chapter called "community voices." We fuse them throughout.

**Exempt pages** (no right column): Cover · Acknowledgement · Contents · Cultural opener spreads · Back Cover · full-bleed photo essays.

---

## Rule 6 — Two service colours per spread, maximum

The brand has seven service-coded colours (Health, Family, Justice, Community, Education, Disability, Wellbeing, Youth, Economic). Editorial rule:

| Page type | Colour rule |
|-----------|-------------|
| **Services directory** (the one page that lists all 30 services) | All seven service colours allowed — it is a directory, that is its job |
| **Featured service spreads** | One service colour owns the spread, with Ocean `#0B4F6C` as the constant |
| **All other spreads** | Maximum two service colours, with Ocean as the constant |
| **Cover · Bwgcolman Way · Next 20 Years** | Hero gradient or cultural palette only; service colours not used |

Most ACCO reports use every brand colour on every page because the brand allows it. We choose not to. The few moments of full colour — the directory, the cover, Next 20 Years — actually land because the rest of the report is restrained.

## How the six rules cohere

| Rule | Pulls toward |
|------|--------------|
| 1 — Photo modes | Restraint |
| 2 — Attribution | Voice |
| 3 — Decoration cadence | Restraint |
| 4 — Caveat for Elders | Voice |
| 5 — Voice-first columns | Voice |
| 6 — Two colours per spread | Restraint |

Voice + Restraint. A publication that trusts its content does not need to shout.

---

## Application checklist (every spread)

Before a spread is signed off:

- [ ] Photo mode is one of the three, applied consistently across the spread
- [ ] Every quote has name · role · year, or it does not appear
- [ ] At most one decorative motif (or zero, if there is a strong photo)
- [ ] If an Elder pull-quote is present, it is Caveat 22pt italic, ≤25 words, Turtle Red border
- [ ] If the page contains data, it has the 33% right column with one attributed quote
- [ ] No more than two service colours, plus Ocean
